## What is Zapier MCP?

Zapier MCP is a hosted Model Context Protocol server that gives AI agents access to 9,000+ app integrations without custom OAuth code. Instead of building individual connectors for Asana, Monday, Gmail, etc., we point our agents at a single Zapier MCP endpoint and get all of them.

How it works:
```
Agent (Claude) ──► POST https://mcp.zapier.com/api/v1/connect  (JSON-RPC 2.0)
                     │   Authorization: Bearer <ZAPIER_MCP_TOKEN>
                     │   method: "tools/call"
                     │   params: { name: "asana_create_task", arguments: { ... } }
                     └── Zapier executes action in connected app
```

## Setup (one-time, requires Zapier account)

1. Go to **https://mcp.zapier.com** → New MCP Server
2. Select **"Other"** as the client type
3. Name it: `Enterprise Claude Skills Platform`
4. Click **+ Add tool** and enable:
   - Asana: Create Task
   - Monday.com: Create Item
   - Gmail: Send Email
   - HubSpot: Create Contact (optional)
   - Slack: Send Channel Message (optional — we have direct Slack already)
5. Connect your app accounts when prompted
6. Click **Connect tab** → **Generate token**
7. Copy the Bearer token

## Configuration

Add to `.env` on the EC2 server:

```bash
ZAPIER_MCP_ENABLED=true
ZAPIER_MCP_TOKEN=your-zapier-bearer-token-here
ZAPIER_MCP_ENDPOINT=https://mcp.zapier.com/api/v1/connect
```

Then restart the backend:
```bash
docker compose restart backend
```

Verify:
```bash
curl -s http://localhost:3000/api/mcp/status | python3 -m json.tool
# Should show: "ok": true, "tool_count": N
```

## API Endpoints

### `GET /api/mcp/status`
Check if Zapier MCP is connected.

**Response (connected):**
```json
{
  "enabled": true,
  "ok": true,
  "mode": "live",
  "tool_count": 4,
  "checked_at": "2026-06-25T..."
}
```

**Response (not configured):**
```json
{
  "enabled": false,
  "ok": false,
  "mode": "unconfigured",
  "error": "ZAPIER_MCP_TOKEN not set"
}
```

### `GET /api/mcp/tools`
List all enabled Zapier tools/actions.

**Response:**
```json
{
  "enabled": true,
  "tool_count": 4,
  "tools": [
    { "name": "asana_create_task", "description": "Create a task in Asana" },
    { "name": "gmail_send_email",  "description": "Send an email via Gmail" }
  ]
}
```

### `POST /api/mcp/execute`
Execute a Zapier tool.

**Body:**
```json
{
  "tool_name": "asana_create_task",
  "params": {
    "name": "Follow up with agency lead",
    "notes": "Generated by SEO Content Writer skill run",
    "projects": ["PROJECT_GID"]
  },
  "task_id": 24
}
```

**Response (success):**
```json
{
  "ok": true,
  "tool_name": "asana_create_task",
  "data": { ... }
}
```

**Error codes:**
- `400` — missing `tool_name`
- `503` — Zapier MCP not enabled
- `502` — Zapier returned an error

## Usage in agent workflows

When a skill run completes, agents can call Zapier tools to push results to external apps.

Example flow:
```
1. POST /v1/tasks  (mkt_seo_content)
2. POST /v1/tasks/:id/run  → Globex Agent routed
3. Agent calls POST /api/mcp/execute:
   tool_name: "asana_create_task"
   params: { name: "SEO article complete", notes: "task_id=24" }
4. Asana task created automatically
5. integration_events row logged for audit
```
